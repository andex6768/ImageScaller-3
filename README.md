## Простая программа для создания атласов из нескольких картинок с гибкими настройками написанная на фреймворке avaloniaUI. Это третья версия програмы до неё были другие менее удачные написанные на других фремворках.Это скорее просто мой учебный проект но он вполне практичен и нормально работает так что может кому-то понадобится.
